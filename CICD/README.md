# CICD - Weaknesses in CICD Pipelines (C)

### Related CWE(s): ARAŞTIRILMADI
### Related CVE(s): ARAŞTIRILMADI

CI/CD (Continuous Integration and Continuous Delivery) represents the automated software delivery pipeline through which code is built, tested, packaged, and released into production. While CI/CD drastically increases productivity, delivery speed, and consistency, it also expands the attack surface across every component of the pipeline. In this category, we address the critical components of pipeline security as well as major risk areas such as pipeline poisoning and insufficient logging that must be carefully controlled throughout the CI/CD lifecycle.
